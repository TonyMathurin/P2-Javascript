Opdracht 2: JavaScript-onderzoek

Hieronder staan de antwoorden op de onderzoeksvragen over HTML en JavaScript.

1. Wat is het verschil tussen een script-tag in de head en onderaan de HTML?

In de <head> zonder defer: de browser pauzeert het verwerken van de HTML terwijl het script wordt opgehaald en uitgevoerd. Daardoor kan de pagina later zichtbaar worden. Als het script HTML-elementen nodig heeft, zijn die mogelijk nog niet aangemaakt.
Onderaan, vlak voor </body>: de browser heeft de HTML erboven al verwerkt voordat het script wordt uitgevoerd. Daardoor kan het script die elementen direct gebruiken. Het script zelf wordt op dat moment nog wel opgehaald en uitgevoerd.

2. Wat doet het attribuut defer in de script-tag?

Met defer kan de browser een extern script downloaden terwijl de HTML verder wordt verwerkt. Het script wordt uitgevoerd nadat de HTML is verwerkt, en vóór het DOMContentLoaded-event. Meerdere scripts met defer worden uitgevoerd in de volgorde waarin ze in de HTML staan.

3. Wat is het verschil tussen HTML en JavaScript?

HTML beschrijft de structuur en inhoud van een webpagina, zoals koppen, alinea's en knoppen.
JavaScript is een programmeertaal waarmee je gedrag en interactiviteit aan een webpagina toevoegt, bijvoorbeeld reageren op klikken of inhoud aanpassen.

Bonus

Wat is het verschil tussen innerHTML en innerText?

innerText leest of wijzigt de zichtbare tekst van een element.
innerHTML leest of wijzigt de HTML-inhoud van een element, inclusief eventuele HTML-tags. Gebruik innerHTML voorzichtig met inhoud van onbekende bronnen.
